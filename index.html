🤖 Dictée & correction IA

Dites une phrase en chinois au micro : Voxtral transcrit ce que l'IA entend, puis Mistral vous explique en français comment corriger votre prononciation (consonnes, tons, conseils articulatoires).

Vous écrivez la phrase à prononcer comme vous voulez : en 汉字 ou en pinyin (aucun choix préalable, les deux fonctionnent). Nécessite une clé API Mistral : le mode vous guide pas à pas.

声母 Consonnes

S, SH, X, J, ZH, Q, CH, C, Z, N, L, R… Les paires qui vous font trébucher.

    声调 Tons

    Les quatre tons : haut, montant, descendant-remontant, tombant.

        🤖 Dictée & correction IA
        🔑 Il manque la clé API Mistral (à faire une seule fois) :
        1. Ouvrez console.mistral.ai → rubrique API Keys → bouton New key.
        2. Donnez-lui un nom (ex. « pinyin-coach ») et validez.
        3. Copiez la clé tout de suite : elle n'est affichée qu'une seule fois.
        4. Collez-la dans « Clé API » ci-dessous (les réglages sont déjà ouverts) et cliquez Enregistrer.
        Selon votre compte, la console peut demander l'ajout d'un moyen de paiement pour activer l'accès API. La clé reste ensuite stockée uniquement dans ce navigateur.
