        🤖 Parler & se faire corriger
        🔑 Il manque la clé API Mistral (à faire une seule fois) :
        1. Ouvrez console.mistral.ai → rubrique API Keys → bouton New key.
        2. Donnez-lui un nom (ex. « pinyin-coach ») et validez.
        3. Copiez la clé tout de suite : elle n'est affichée qu'une seule fois.
        4. Collez-la dans « Clé API » ci-dessous (les réglages sont déjà ouverts) et cliquez Enregistrer.
        Selon votre compte, la console peut demander l'ajout d'un moyen de paiement pour activer l'accès API. La clé reste ensuite stockée uniquement dans ce navigateur.
